# Customer Behaviour & Dimensionality Reduction

**Направление:** Data Analytics / Customer Analytics

Проект по анализу поведения клиентов интернет-магазина и снижению размерности данных с помощью PCA и t-SNE.

## Цель проекта

Исследовать структуру клиентских данных, выделить наиболее информативные признаки и сократить размерность без существенной потери информации.

## Данные

В анализе используется датасет с информацией о 1000 клиентах интернет-магазина.

Признаки описывают:

- демографические характеристики;
- тип подписки;
- активность на сайте;
- историю покупок;
- используемую платформу;
- факт покупки в прошлом месяце.

Перед анализом были обработаны пропуски, закодированы категориальные признаки и выполнена стандартизация.

## Стек

Python · pandas · NumPy · scikit-learn · matplotlib · seaborn

## Отбор признаков

Для предварительного анализа использовалась корреляционная матрица.

Наиболее заметная положительная связь с фактом покупки наблюдалась у:

- `Membership_Premium` — около 0,30;
- `Visits_per_Month` — около 0,29;
- `Previous_Purchases` — около 0,20;
- `Total_Purchase_Value_USD` — около 0,15;
- `Pages_Visited_per_Session` — около 0,14.

После дополнительной проверки итоговый набор был сокращён до 10 признаков.

## Проверка пригодности для PCA

Для оценки структуры данных использовались:

- KMO;
- тест Бартлетта.

Итоговое значение KMO составило около **0,749**.

Тест Бартлетта оказался статистически значимым (`p < 0.001`), что подтверждает пригодность выбранных признаков для PCA.

## PCA

Для уменьшения размерности использован метод главных компонент.

Итогово выбрано **7 компонент**, которые сохраняют около **89,7% исходной дисперсии**.

Первая компонента в основном связана с активностью и покупательской ценностью клиента, а вторая — со средним чеком и денежными характеристиками покупок.

## t-SNE

Для исследования локальной структуры данных были протестированы значения perplexity:

- 10;
- 30;
- 50;
- 100.

Наиболее содержательный результат получен при `perplexity = 30`.

Для этого варианта показатель trustworthiness составил около **0,984**, что говорит о хорошем сохранении локального соседства объектов.

## Основные выводы

- 10 исходных признаков удалось сократить до 7 главных компонент с сохранением около 89,7% информации.
- PCA хорошо подходит для сжатия и интерпретации структуры данных.
- t-SNE позволяет лучше увидеть локальные группы и соседство клиентов.
- Покупатели и непокупатели не образуют полностью отдельных групп.
- Premium-подписка, более высокая активность и история предыдущих покупок чаще встречаются у клиентов, совершивших покупку.
